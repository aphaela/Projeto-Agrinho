# 
Agrinho 2026

Versão avançada do projeto com estética editorial inspirada em referências de Notion/Pinterest e foco em experiência interativa.

Tema: **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”.**

## O que há nesta versão

- Hero ilustrado em CSS, sem depender de uma imagem externa para a abertura.
- Navegação fixa e modo claro/escuro.
- Mapa interativo da propriedade com quatro pontos exploráveis.
- Seção de sistemas: solo, água, tecnologia e biodiversidade.
- Filtros de soluções por categoria.
- Jogo “Fazenda 2035”, com indicadores de produção, natureza e recursos.
- Compromisso final interativo.
- Animações de entrada e microinterações.
- Layout responsivo para celular, tablet e computador.

## GitHub Pages

Envie `index.html`, `style.css` e `script.js` para a raiz de um repositório.

Depois:
**Settings → Pages → Deploy from a branch → main → /(root)**.

O site não usa frameworks ou build. Basta abrir `index.html`.
